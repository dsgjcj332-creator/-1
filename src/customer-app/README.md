# Customer Mobile App (Port 5174)

This module represents the complete customer mobile application for Ala El Saree («عالسريع»).

- **Port**: 5174
- **Components**: `src/components/screens/`, `src/components/layout/`, `src/context/AppContext.tsx`
- **Features**: Garment selection, customized fragrance/starch/packaging, garment photo verification, laundry partner selection, scheduling, tracking, and customer account.
